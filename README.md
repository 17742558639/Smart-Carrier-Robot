# 智能物流搬运机器人（NUEDC 智能搬运赛项）

基于 STM32F407 的四轮麦克纳姆轮全向底盘 + 四轴机械臂，用于中国大学生工程实践与创新能力大赛「智能+工程创新赛道 · 智能搬运」赛项。

## 硬件组成

| 部件 | 型号 / 接口 | 说明 |
|---|---|---|
| 主控 | STM32F407VETx | HAL 库，Keil MDK 工程 |
| 底盘 | 4x Emm_V5 闭环步进电机 | USART1，四轮麦克纳姆轮全向移动 |
| 姿态 | HWT101 陀螺仪 | USART3，闭环转向 |
| 视觉 | MaixCam Pro | USART2，二维码 / 物料识别 |
| 交互 | HMI 串口屏 | USART6 @9600，指令下发与状态显示 |
| 机械臂 | 4 关节舵机 | TIM1 四路 PWM（J1~J3 为 360 度型，J4 为 270 度型） |

## 关键实现

### 1. 麦克纳姆轮运动学

四轮速度分解（前进 / 横移 / 自转解耦）：

```
w1 =  y - x        // 右前
w2 = -y + x        // 右后
w3 = -(y + x)      // 左前
w4 = -(-y - x)     // 左后
```

四电机位置指令先各自缓存，再由地址 0 广播 `Synchronous_motion` **同步启动**，避免逐个下发导致的起步不同步。

### 2. IMU 闭环转向

- 误差归一化到 ±180 度，取最短转向方向
- 单次修正限幅 30 度、累计限幅 270 度、最多 12 次修正
- 每步转完必须等到**新的** IMU 帧才判断，禁止用旧角度下结论
- 连续两次「转了 ≥5 度但 yaw 变化 <1 度」判定 IMU 无响应，立即停车

### 3. 路径规划与执行

- 5x5 静态栅格地图，BFS 求最短路径
- 同方向连续格子合并成段，每段最多走 82cm 就停一次用 IMU 复核绝对朝向
- 段头先走 5cm 留观察窗口，带死循环保护与坐标合法性检查

### 4. 粗定位状态机

四阶段循环推进：

```
CoarseStartCorrect -> CoarseBfsNavigate -> CoarseStationAlign -> CoarseStationDwell
    启动校正              路径导航              到站对准            到站停顿
```

目标链：二维码区 → 原料区 → 粗加工区 → 暂存区 → 返回启停区，任一环节失败进入 `CoarseFault` 并记录故障码。

## 已知问题

- 车体存在系统性走偏：前进时车头右偏、后退时车尾左偏（同向顺时针），实测左/右轮轨迹差约 8cm 而平均值正好等于命令距离，推断为**轮子安装几何偏差**（待查平行度 / 共面度）
- 麦轮横移存在几何损失（横移速度约等于 0.707 倍轮速），纵向与横移目前共用同一换算系数
- `RunMove` 的等待时间余量为经验值（300ms），需实车标定
